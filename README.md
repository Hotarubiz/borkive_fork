# 봇카이브

리스(RisuAI)에 다 넣어 두기 버거운 봇을 **파일로 꽂아 두는 내 서재**예요.
봇마다 카드 파일, 소개글, 채팅 로그, 모듈 같은 자료, 링크, 메모를 한곳에 모아 둬요.

> 혼자 쓰는 앱이에요. 내 컴퓨터나 내 기기끼리만 열어 두세요. 비밀번호 잠금을 켤 수 있지만 기본은 꺼져 있고, 잠가도 인터넷에 공개하는 건 권하지 않아요.

## 무엇을 할 수 있나요

- **봇 꽂기:** 리스에서 내보낸 카드(.charx · .png · .jpeg · .json)를 넣거나 리스 랠름 주소를 붙여 넣으면 이름·표지·로어북 수를 읽어 와요.
- **버전:** 업데이트마다 카드·모듈·소개글을 한 묶음으로 남겨요.
- **소개글:** 아카라이브 글 주소로 가져오거나(그림까지 보관) 붙여 넣어요. 한 봇에 여러 개를 둘 수 있어요.
- **채팅 로그:** 리스에서 내보낸 채팅(.json · .jsonl)을 책처럼 읽어요. 시리즈로 묶기, 화 번호 정하기, 장면 표시(메모·그림)를 할 수 있어요. 카드의 표시용 정규식을 읽어서 에셋 그림도 보여 줘요.
- **들여다보기:** 카드·모듈 속 로어북과 에셋을 리스 없이 봐요.
- **정리:** 폴더, 상태(하는 중·찜·끝 + 직접 더하기), 태그, 검색, 정렬, 카드 크기를 쓸 수 있어요.
- **자료함:** 모듈·프리셋·로어북·플러그인을 봇처럼 카드로 모아요. 종류도 직접 더할 수 있어요.
- **페르소나:** 채팅할 때 쓰는 '나'를 그림 한 장 + 프롬프트 + 메모로 모아 둬요. 같은 사람의 여러 버전(탐험가용 · 헌터물…)은 한 폴더에 모이고, 폴더 페이지에서 버전마다 탭으로 넘겨 봐요. 표지를 누르면 그 버전 그림만 바로 바꿀 수 있고(끌어 놓기 · 붙여넣기 · 다른 버전 그림 쓰기), 버전을 그림 · 모듈까지 통째로 복제할 수도 있어요. 버전마다 프롬프트 · 로어북 · 에셋(페르소나용 모듈 속) · 갤러리 탭이 있고, 갤러리에는 그림을 마음대로 올려 두고(버전 전용 또는 폴더 공통) 메모를 달거나 버전 그림으로 쓸 수 있어요. 폴더마다 분류(기본 남캐 · 여캐, 설정에서 더하기)를 정해 위 칸으로 거를 수 있어요. 버전마다 페르소나용 모듈(.risum)도 하나 붙일 수 있어요. 리스에서 내보낸 페르소나 PNG를 넣으면 이름·프롬프트를 알아서 읽고, 리스용 PNG로 다시 내려받을 수도 있어요. 채팅 로그마다 페르소나를 고를 수 있고, 봇에 기본 페르소나를 정해 두면 새로 올리는 로그에 알아서 붙어요.
- **그림체:** 그림 생성용 프롬프트(작가·스타일 태그)를 견본 그림과 함께 모아 두고 버튼 하나로 복사해요. NAI·웹UI로 뽑은 PNG를 넣으면 프롬프트·설정을 알아서 읽어요. 흑백 · 채색 진하게 같은 변형을 탭으로 나눠 두고(변형마다 프롬프트 · 견본 그림), 갤러리에 그림을 마음대로 모아 둘 수 있어요(NAI 그림이면 프롬프트도 같이 읽음). 봇과 이어 둘 수 있고(공식·어울림), 파일(`.botkive-style.json`)로 내보내서 나눠 줄 수 있어요(갤러리는 빼고).
- **설정**(왼쪽 아래 톱니, 홈에서는 위쪽): 테마·글꼴, 상태·종류·분류 이름표, 내보내기·들이기, 잠금을 한곳에 모았어요.
- 자료는 **하루 한 번 자동 백업**돼요(30일치). 필요하면 **비밀번호 잠금**도 걸 수 있어요(끔 · 밖에서만 · 항상).

## 설치

### LLM에게 맡기기 (제일 쉬움)

Claude Code, Codex, Cursor 같은 코딩 LLM에게 아래처럼 부탁하세요. 이 저장소의 [AGENTS.md](AGENTS.md)에 LLM이 따라 할 설치 순서가 적혀 있어요.

```
https://github.com/redarchive77-coder/botkive 를 받아서 AGENTS.md의 '설치 맡기기' 순서대로 봇카이브를 설치해 줘.
내 컴퓨터는 윈도우야. 다 되면 브라우저로 열 주소를 알려 줘.
```

### 직접 하기 — 도커

[Docker Desktop](https://www.docker.com/products/docker-desktop/)(윈도우·맥)이나 도커(리눅스)가 있으면 이게 제일 편해요.

```bash
git clone https://github.com/redarchive77-coder/botkive.git
cd botkive
mkdir data
docker compose up -d
```

브라우저에서 **http://127.0.0.1:8391** 을 여세요.

- 포트를 바꾸려면 `.env.example`을 `.env`로 복사해서 `BOTSHELF_PORT`를 고치세요.
- 리눅스에서 `data` 폴더에 쓸 수 없다는 오류가 나면 `.env`의 `BOTSHELF_UID`·`BOTSHELF_GID`를 `id -u`·`id -g` 값으로 맞추세요.

### 직접 하기 — 파이썬만

파이썬 3.12 이상만 있으면 돼요. 따로 설치할 패키지는 없어요.

```bash
# 맥·리눅스
cd botkive/app
DATA_DIR=../data python3 server.py
```

```powershell
# 윈도우 PowerShell
cd botkive\app
$env:DATA_DIR = "..\data"; python server.py
```

브라우저에서 **http://127.0.0.1:8391** 을 여세요. 창을 닫으면 앱도 꺼져요.

## 휴대폰 같은 다른 기기에서 쓰기

**[Tailscale](https://tailscale.com/)로 내 기기끼리만** 여는 걸 추천해요. 앱이 켜진 컴퓨터와 휴대폰에 Tailscale을 깔고 같은 계정으로 로그인한 뒤, 앱이 켜진 컴퓨터에서:

```bash
tailscale serve --bg --https=8443 http://127.0.0.1:8391
```

그러면 내 기기에서만 `https://<컴퓨터 이름>.<tailnet 이름>.ts.net:8443` 으로 들어갈 수 있어요.

이런 건 **하지 마세요.** 모두 아무나 들어올 수 있게 돼요.
- 공유기 포트포워딩
- `tailscale funnel`
- ngrok·cloudflared 같은 공개 터널
- `HOST=0.0.0.0`으로 바로 띄우기

## 잠금 (비밀번호)

**설정 → 잠금**에서 비밀번호를 정하고, 언제 물을지 골라요.

| 모드 | 동작 |
|---|---|
| 끔 (기본) | 비밀번호를 묻지 않아요 |
| 밖에서만 | 이 컴퓨터에서 바로 열 땐 그냥 들어가고, 휴대폰·다른 기기(Tailscale·같은 와이파이)로 들어오면 물어요 |
| 항상 | 어디서 열든 물어요. 같이 쓰는 컴퓨터라면 이걸로 하세요 |

- 로그인하면 그 브라우저에서 30일 동안 기억해요. 비밀번호를 바꾸면 다른 기기의 로그인은 모두 풀려요.
- 비밀번호를 5분 안에 5번 틀리면 잠깐 막혀요.
- 다른 기기에서 쓸 때는 **Tailscale + 잠금 '밖에서만'** 조합을 추천해요.
- 잠가도 공개 인터넷에 여는 건 권하지 않아요. 앱 자체에 HTTPS가 없고, 혼자 쓰려고 만든 서버예요.

**비밀번호를 잊었을 때**
- 도커: `.env`에 `BOTSHELF_RESET_AUTH=1`을 넣고 `docker compose up -d` → 잠금이 풀려요. 풀린 뒤 그 줄을 비우고 다시 `docker compose up -d`.
- 파이썬: `RESET_AUTH=1`을 붙여 한 번 켜고(`RESET_AUTH=1 DATA_DIR=../data python3 server.py`), 다음부터는 빼고 켜요.

## 자료는 어디에

모두 `data` 폴더에 있어요.

| 위치 | 내용 |
|---|---|
| `data/botshelf.db` | 봇·채팅 로그·소개글·메모 (SQLite) |
| `data/bots/0012/` | 봇 하나의 원본 파일. `v37/` 같은 버전 폴더 안에 올린 이름 그대로 있어요 |
| `data/bots/0012/info.txt` | 그 봇의 이름·상태·태그·폴더·버전 목록 (사람이 읽는 메모) |
| `data/items/` | 자료함 자료 (봇과 같은 모양) |
| `data/media/` | 표지, 소개글 그림, 장면 그림, 그림체 견본, 페르소나 그림 |
| `data/personas/0003/` | 페르소나용 모듈 원본 |
| `data/backups/` | 자동 백업 (하루 하나, 30일치) |

원본 파일은 올린 그대로라 봇카이브 없이도 리스에 바로 넣을 수 있어요.

**옮기거나 따로 보관하기:** 앱을 끄고 `data` 폴더를 통째로 복사하세요. 새 곳에서 같은 자리에 두고 켜면 그대로 이어져요. 자동 백업은 같은 디스크에 생기니, 가끔은 다른 디스크나 클라우드에도 복사해 두세요.

**전부 내보내기:** **설정 → 내보내기 · 들이기**(홈에서는 맨 아래에도 있어요)에서 **내려받기**를 누르면 `봇/폴더/봇 이름/버전 이름/` 모양의 압축 파일 하나로 받아요. 채팅 로그는 리스 형식(.json), 그림체는 프롬프트 글 파일과 견본 그림이 함께 들어 있고, 갤러리는 그림체 폴더 아래 `갤러리/`에 있어요. 페르소나는 `페르소나/<분류>/<폴더>/<버전>/`(갤러리는 폴더 아래 `갤러리/`)에 프롬프트 글 파일 · 그림 · 모듈로 들어 있고(버전이 하나면 폴더 바로 아래), PNG 그림은 리스의 페르소나 불러오기로 바로 넣을 수 있어요.

**들이기:** 같은 창에서 받아 둔 압축 파일을 고르면 이 서재에 더해요. 폴더 · 상태 · 태그 · 버전 · 소개글 · 채팅 로그 · 그림체 · 페르소나까지 그대로 들어오고, 이름과 만든 사람이 같은 봇은 건너뛰어요. 큰 파일은 조각으로 올리니 끊기면 같은 파일을 다시 고르면 이어서 올려요. 올린 압축 파일과 풀어 넣은 파일이 잠깐 같이 있으니 빈자리가 압축 파일의 두 배쯤 필요해요.

## 업데이트

```bash
git pull
docker compose restart      # 파이썬으로 띄웠다면 껐다가 다시 켜기
```

내 자료(`data`)는 지우지 않아요. 새 기능에 필요한 칸은 켤 때 알아서 더해지고, 바뀌기 전 목록은 `data/backups`에 `pre-…` 이름으로 남겨요.

**2026년 11월 이전에 설치했다면:** 업데이트 뒤 처음 켤 때 원본 파일이 `data/files`(무작위 이름)에서 `data/bots/0012/…`(봇마다 폴더, 원래 이름)로 한 번 옮겨져요. 저절로 되고, 중간에 꺼져도 다음에 켤 때 마저 옮겨요. 옮긴 뒤에는 예전 버전으로 되돌리면 파일을 못 찾으니 되돌리지 마세요.

## 이렇게 생겼어요 (만드는 사람용)

- `app/server.py`: 파이썬 표준 라이브러리만 쓰는 서버 + SQLite. API 목록은 파일 맨 위에 있어요.
- `app/index.html`: 화면 전부가 든 파일 하나. 빌드 도구도, 프레임워크도 없어요.
- 고치는 규칙과 시험하는 법은 [AGENTS.md](AGENTS.md)에 있어요.
